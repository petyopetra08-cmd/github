Mire jó a GitHub?

A GitHub egy online hely, ahol a kódod (vagy bármilyen szöveges projekted) biztonságban van, minden változtatása visszakövethető, és mások is dolgozhatnak rajta veled együtt.

Hogyan kezdjek hozzá?

Verziókezelés: minden változás megvan

A GitHub a Git nevű rendszerre épül. Minden mentést (commit) megőriz, így bármikor visszatérhetsz egy korábbi állapothoz, és láthatod, ki, mikor és mit módosított.

  • Nincs többé „vegleges_v3_javitott_UJ” nevű fájl
  • Egy hiba után egy kattintással visszaléphetsz
  • Az egész projekt története átlátható

Együttműködés: pull request és kódáttekintés

Ha valaki változtatást javasol, nyit egy pull requestet. A csapat megnézi, hozzászól, és csak jóváhagyás után kerül be a változás a fő verzióba.

  • Sorokra bontott megjegyzések, viták
  • Hibák kiszűrése még élesítés előtt
  • Közös tanulás: mindenki látja a másik munkáját

Közösség és nyílt forráskód

A GitHubon milliók osztják meg projektjeiket. Használhatod mások kódját, javíthatsz hibát idegen projekten, vagy bemutathatod a saját munkáidat a portfóliódban.

  • Fork: lemásolod, és a saját ötleteiddel továbbfejleszted
  • Issue: hibát jelzel vagy ötletet vetsz fel
  • Csillag (star): megjelölöd a kedvenc projektjeidet

Automatizálás: a GitHub Actions

Beállíthatod, hogy minden feltöltés után a GitHub magától lefuttassa a teszteket, elkészítse a programot, sőt ki is tegye az oldalra.

  • Kevesebb kézi, ismétlődő munka
  • A hibás kód nem jut át észrevétlenül
  • GitHub Pages: ingyenes weboldal-hosztolás

Így kezdj hozzá

Négy lépés, és már az első projekted is online van.

  1. Fiók létrehozásaRegisztrálj ingyen a github.com oldalon.
  2. Új tárolóKattints a „New” gombra, és adj nevet a projektnek.
  3. Fájlok feltöltéseTöltsd fel a böngészőből, vagy használd a Git parancsokat.
  4. Oszd megKüldd el a linket másoknak, és hívd meg őket közreműködni.
